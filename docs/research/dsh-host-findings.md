- `@deepseek-ai/dsh-skill-filesystem` supports `customSkillDirs`. Global and preset providers merge, but the shipped web profile disables the original global `skill-filesystem`; insert a new uniquely named global provider. Each root scans only `<name>/SKILL.md` or `<name>.md`, with lowercase kebab-case names. Include Codex `.system` and individual plugin `skills` roots separately. Sources: `modules/dsh-skill-filesystem/lib/index.js:31`, `modules/dsh-web-app/cordis.patch.yml:475`.

Exclude non-text reasoning blocks, compact provider streams and replay state. Cold-safe reads use `ctx.sessionQuery.observeSession(id, {signal,projectionMode:'none'})`, followed by disposal. Sources: `modules/dsh-agent-loop/lib/index.js:682`, `:697`, `:1144`, `modules/dsh-session-query/lib/index.js:1062`.

- Installed third-party Mnemon's `mnemonMemory` service accepts contribution definitions; it is not an unrestricted memory-engine read/write API. A new explicit shared-notes storage is an implementation choice, not a recovered private memory interface.
